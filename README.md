# Cafe Cuddle - Cafe Management Web Application

## Project Description

Cafe Cuddle is a simple Cafe Management Web Application developed from
a basic C-based cafe ordering program.

The application allows customers to view the cafe menu, select food
and beverages, enter their name, specify the number of cups, calculate
the total price and generate a printable bill.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

1. Cafe Cuddle homepage
2. Coffee menu
3. Tea menu
4. Customer name input
5. Item selection
6. Number of cups
7. Add items to order
8. Multiple items in one order
9. Remove items
10. Automatic subtotal calculation
11. Automatic total bill calculation
12. Bill generation
13. Date and time on bill
14. Printable receipt
15. Clear order
16. Responsive mobile design

## How to Run

1. Download or create the project folder.
2. Open the folder using Visual Studio Code.
3. Make sure these files are present:

   - index.html
   - style.css
   - script.js

4. Open `index.html` in your browser.

### Recommended Method

Install the Live Server extension in Visual Studio Code.

Then:

Right Click on `index.html`
→ Open with Live Server

The application will open in your browser.

## C Program to Web Application Mapping

| C Program | Web Application |
|---|---|
| Menu Card | Menu Section |
| Customer Name | Customer Name Input |
| Select Order | Item Selection |
| Number of Cups | Quantity Input |
| price * cups | JavaScript Calculation |
| Total Bill | Automatic Total |
| Bill | Digital Receipt |
| getch() | Not required |
| clrscr() | Not required |
